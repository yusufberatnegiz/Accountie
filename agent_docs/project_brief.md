# Project Brief

- **Ürün:** Accountie
- **Vizyon:** Muhasebe ofisinin resmî beyan, ödeme ve mevzuat takibini tek güvenilir ekranda toplamak.
- **Kullanıcılar:** Aynı ofisteki admin ve staff kullanıcıları.
- **Problem:** GİB, SGK ve Resmî Gazete bilgileri dağınık; süre ve değişiklik takibi manuel yapılıyor.
- **Temel döngü:** Kaynakları tara → değişikliği admin incelesin → yayımla → ekip dashboard/takvim/akıştan takip etsin.
- **Mutlaka çıkacak:** Auth/roller, dashboard, takvim, üç resmî kaynak, admin review, güncel akış, notlar ve favoriler.
- **MVP dışında:** Luca, muhasebe/evrak işlemleri, AI, çoklu ofis, SMS/WhatsApp, ödeme/beyan gönderimi.
- **Teslim hedefi:** 3 gün.
- **Ürün ilkesi:** Kaynaksız bilgi yayımlama; otomasyon hatasını kullanıcıdan saklama; kritik değişikliği onaysız yayımlama.

Detaylı gereksinimler için `docs/PRD-Accountie-MVP.md` dosyasını oku.
