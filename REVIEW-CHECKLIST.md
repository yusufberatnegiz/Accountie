# Accountie MVP Kontrol Listesi

- [ ] Public signup kapalı ve login/logout/session akışı çalışıyor.
- [ ] Tüm oturum açmış kullanıcılar aynı ekran ve `Şimdi tara` yetkisine sahip.
- [ ] GİB, SGK ve Resmî Gazete canlı taraması resmî URL üretmiş.
- [ ] Aynı tarama tekrarlandığında kopya kayıt oluşmuyor.
- [ ] Bir kaynak bozulduğunda diğerleri çalışıyor ve eski veriler silinmiyor.
- [ ] Kaynak sağlığı başarılı/başarısız son çalışmayı gösteriyor.
- [ ] Dashboard GİB/SGK, bugün ve 7 gün sayılarını doğru hesaplıyor.
- [ ] Takvim arama, kaynak, işlem, vergi türü, aciliyet, tarih ve geçmiş filtrelerini uyguluyor.
- [ ] Güncel akış GİB/SGK/Resmî Gazete filtrelerini, favori ve okundu durumunu koruyor.
- [ ] Not oluşturma, düzenleme, silme, tamamlama, tarih, hatırlatma ve kayıt bağlantısı çalışıyor.
- [ ] Kullanıcı yalnızca kendi not/favori/okundu kayıtlarını değiştirebiliyor.
- [ ] Cron endpoint yanlış veya eksik secret ile 401 dönüyor.
- [ ] `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` geçiyor.
- [ ] Masaüstü ve mobil dashboard/takvim/akış/notlar smoke testi geçiyor.
